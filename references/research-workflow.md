# 文献研究工作流

## 适用范围

这是一个以本地文献为封闭证据库的研究工作流。它适合回答领域综述、理论比较、机制分析、研究设计参考和出处定位问题。它不等同于联网检索，也不保证覆盖尚未纳入索引的 PDF。

## 标准流程

### 1. 明确研究问题

将用户问题改写成可检索的问题，并保留范围约束：研究对象、现象、时间段、地区、理论、方法或期刊。

### 2. 候选文献筛选

使用 `search_corpus.py` 获得候选文献。关键词不足时，补充同义词、英文关键词、理论名称和可能的研究对象，但不要扩大到语料库之外。

### 3. 证据提取

使用 `extract_evidence.py` 生成正文片段，然后回到原始 Markdown 核对上下文。每篇文献至少记录：

| 字段 | 内容 |
|---|---|
| 研究问题 | 作者试图解释或回答什么 |
| 理论框架 | 使用的概念、理论或分析视角 |
| 方法与材料 | 样本、数据、案例和研究方法 |
| 主要发现 | 作者明确报告的结果 |
| 局限 | 作者指出或文本明确显示的限制 |
| 证据位置 | 文件相对路径、章节或片段 |

### 4. 跨文献综合

按照“主题—机制—证据—边界”的顺序综合：

- 主题：多篇文献共同讨论了什么；
- 机制：文献如何解释现象；
- 证据：结论来自何种方法和材料；
- 边界：结论适用于什么情境，哪些情境尚未覆盖。

同一文献的翻译稿、清洗稿、渲染稿或重复副本只能作为一个证据来源。

### 5. 输出研究报告

推荐结构：

1. 结论摘要；
2. 文献范围与检索口径；
3. 主题或理论脉络；
4. 机制和证据比较；
5. 共同发现与争议；
6. 研究缺口；
7. 证据表和来源路径；
8. 语料覆盖限制。

## 证据分级

- **直接证据**：原文明确陈述、报告或测量的内容；
- **综合判断**：由两篇或以上文献的共同信息归纳而来；
- **分析推论**：根据文献进行的合理解释，必须明确标为推论；
- **未证实内容**：语料中没有足够支持，不得写成事实。

## 不足证据时的写法

使用以下表达：

> 当前已索引语料中未找到足够证据支持该判断。

并说明是“没有命中文献”“只有间接证据”，还是“已有 PDF 尚未转换为 Markdown”。
